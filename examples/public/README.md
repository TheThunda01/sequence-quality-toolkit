# Public sequence data

The file `ERR458493_first1000.fastq.gz` is a 1,000-record prefix from ENA run ERR458493, project PRJEB5348 (*Saccharomyces cerevisiae* RNA-seq). It is real archived read data, separate from the synthetic fixtures elsewhere in this repository.

This data file is **not licensed under the project's MIT code license**. See the [source, derivation, attribution, and ENA/INSDC terms](../../docs/public-data.md), and retain `provenance.json` when sharing the excerpt. The prefix is not a random or representative sample of the complete run.

The source study is [Schurch et al. (2016)](../../docs/references.md#schurch-2016), *RNA*, 22(6), 839–851, with an [associated erratum](../../docs/references.md#schurch-erratum-2016). The [glossary](../../docs/glossary.md) defines the archive and sequence terms, and the [reference audit](../../docs/reference-audit.json) records current source-access limits.
