# Contributing

Thanks for taking a look. A useful contribution starts with a small example that makes the problem clear.

Run the checks in the README before submitting a change. If an analysis rule changes, update its tests, methods, and example outputs together. Keep input data separate from generated results. Please do not include private participant records, access tokens, or data you cannot redistribute.

When you add a scientific statement, cite a primary paper or an authoritative methods source and explain what the evidence supports. An attractive figure or a passing test does not validate a biological conclusion.

These are learning-focused projects. The initial implementation and documentation were developed with AI assistance and checked with executable examples. Contributions and substantive human revisions should be described honestly in the commit or pull request.
